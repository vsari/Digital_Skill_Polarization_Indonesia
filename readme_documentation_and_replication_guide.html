1. Overview

This documentation describes the datasets and Stata programming files (do-files) used to produce the descriptive statistics, main analysis, and robustness checks for the paper titled The Promise and Peril of Digital Technology: Evidence from Digital Skill Polarization in Indonesia.

 

The do-files are numbered in the order in which they should be executed (section 4). The master do-file contains the complete workflow and should be run first.

 

The programming files produce all tables and figures presented in the manuscript and its appendices.

 

2. Software requirement

The analysis was conducted using Stata/MP 18.0 on macOS. The required user-written commands must be installed before running the analysis. The 0_master.do file installs them automatically and should therefore be run first.

 

3. Data source and sample

 

Data

Data                            : Digital Economy and Household Survey, Indonesia (World Bank, 2020)

Download link             : https://doi.org/10.48529/3vrg-x206

 

The paper uses the 2020 Indonesia Digital Economy Household Survey, published by the World Bank. The data are publicly available and can be downloaded from the link above.

 

The survey provides detailed information on Indonesia’s digital economy. It covers 3,063 households across 311 enumeration areas and is representative of Indonesia’s major island regions. It comprises six modules covering household and individual characteristics, internet access and use, service delivery, e-commerce, digital finance, and household enterprises.

 

The analysis uses these modules: household and individual characteristics, and internet access and use.

 

Unit of analysis and sample criteria

The unit of analysis is individual. The sample comprises internet users in Indonesia aged 15 years or older who used the internet in the year preceding the survey. The final sample includes 3,181 individuals. No missing data were observed for the variables included in the analysis; therefore, no observations were excluded from the final sample.

4. Replication package structure

The analysis is implemented through a series of Stata do-files that process the raw data and generate all results reported in the manuscript. The do-files should be run sequentially in the order shown in the table below. Raw data refers to the original DEHS 2020 survey data, while coded data refers to the processed dataset containing the variables required for the analysis.

 

Folder structures

 

The “replication” folder package consists of four folders.

Folder name

Description

1_rawdata

Contains the raw data (World Bank Digital Economy and Household Survey, Indonesia 2020)

2_codeddata

Contains processed data for the descriptive and main analysis

3_dofile

Contains all the coding scripts to clean data, analysis, produce results, and run robustness checks for the empirical models.

4_output

Contains all outputs. The sub-folders:

·       Figure – outputs in figures form

·       Regression – stores ologit and multinominal logit estimations

·       Robustness – runs robustness checks of the empirical models

·       Table – stores output tables discussed in the manuscript

5. Running the analysis and robustness check

 

For replication, follow these steps in order:

1.     Download and unzip folder “replication” package without changing its folder structure.

2.     Save the unzipped folder on your computer and note its file path.

3.     In Stata, open 0_master.do from the 3_dofile folder and enter the file path on the designated line under "User setup."

4.     Run 0_master.do before any other programming files. The master do-file automatically installs the required user-written commands, executes the entire workflow, prepares the raw data, and produces all results and robustness checks.

5.     The outputs are saved in the designated folders described in the next section.
